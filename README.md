# 📈 AI-Driven Stock & Crypto Market Trend Analyzer

A fully end-to-end Python project that combines **technical analysis**, **machine learning**, **LSTM neural networks**, and **NLP sentiment analysis** to forecast and analyse stock & crypto market trends — served through an interactive **Streamlit** dashboard.

---

## 🗂️ Project Structure

```
crypto/
├── dashboard/
│   └── app.py              ← Streamlit web dashboard (main UI)
├── data/
│   ├── fetcher.py          ← Data ingestion (yfinance + CoinGecko)
│   └── preprocessor.py     ← Feature engineering & scaling helpers
├── features/
│   └── indicators.py       ← 40+ technical indicators (ta library)
├── models/
│   ├── ml_model.py         ← RandomForest / GradBoost / SVM / LR
│   ├── lstm_model.py       ← Bidirectional LSTM price forecaster
│   └── sentiment.py        ← VADER NLP + Fear & Greed Index
├── analysis/
│   └── trend_analyzer.py   ← End-to-end pipeline orchestrator
├── visualization/
│   └── charts.py           ← Plotly interactive charts
├── data_cache/             ← Auto-created CSV cache (6h TTL)
├── saved_models/           ← Auto-created model persistence
├── config.py               ← All global settings
├── main.py                 ← CLI entry point
└── requirements.txt
```

## ⚙️ Installation

```bash
# 1. Create & activate a virtual environment (recommended)
python -m venv venv
venv\Scripts\activate          # Windows
# source venv/bin/activate     # macOS / Linux

# 2. Install dependencies
pip install -r requirements.txt
```

> **Note:** TensorFlow (for LSTM) may take several minutes to install.  
> If you encounter issues, install it separately: `pip install tensorflow`

---

## 🚀 Usage

### Option A — Interactive Dashboard (recommended)
```bash
streamlit run dashboard/app.py
```
Open **http://localhost:8501** in your browser.

### Option B — CLI (headless)
```bash
# Stock analysis
python main.py --symbol AAPL --type stock --period 1y

# Crypto analysis (skip LSTM for speed)
python main.py --symbol BTC --type crypto --no-lstm

# With custom epochs and NewsAPI key
python main.py --symbol TSLA --type stock --epochs 100 --news-key YOUR_KEY
```

## 🧠 AI / ML Components

| Component | Technology | Output |
|-----------|-----------|--------|
| Trend Classifier | Random Forest, Gradient Boosting, SVM, Logistic Regression | BUY / HOLD / SELL (3-class) |
| Price Forecast | Bidirectional LSTM (TensorFlow/Keras) | Next 30-day prices |
| Sentiment | VADER NLP → textual headlines | Score −1 … +1 |
| Fear & Greed | CoinGecko API (crypto only) | 0 … 100 index |

## 📊 Technical Indicators (50+)

- **Trend:** SMA, EMA, MACD, ADX, CCI, Vortex, TRIX  
- **Momentum:** RSI, Stochastic %K/%D, Williams %R, ROC  
- **Volatility:** ATR, Bollinger Bands, Donchian Channel  
- **Volume:** OBV, CMF, MFI, VWAP, EOM, Force Index  
- **Cross-signals:** EMA alignment, MACD crossover, RSI extreme zones
